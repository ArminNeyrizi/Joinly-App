# AI Code Conventions & UI Rules

## استانداردهای رابط کاربری (UI/UX)
* تمام صفحات باید کاملاً فارسی، روان و راست‌چین باشند.
* ویژگی `dir="rtl"` در تگ‌های اصلی کدهای فرانت‌اند رعایت شود.
* فونت اصلی پروژه **Kalameh** است که در مسیر `src/assets/fonts/` قرار دارد.
* استفاده از فریم‌ورک **Tailwind CSS** برای استایل‌دهی الزامی است.
* مقادیر رنگ، شعاع (Radius) و فاصله‌ها (Spacing) باید دقیقاً از فایل‌های موجود در مسیر `src/config/` خوانده شوند و از مقادیر هاردکد شده جلوگیری شود.
* برای ساخت فرم‌ها، کارت‌ها و دکمه‌ها حتماً از کامپوننت‌های آماده پروژه در پوشه `src/components/ui/` استفاده شود.

---

## قوانین Next.js و رندرینگ
* به صورت پیش‌فرض تمام صفحات و کامپوننت‌ها باید **Server Component** باشند تا سرعت بارگذاری بالا بماند.
* عبارت `'use client'` فقط و فقط زمانی استفاده شود که به هوک‌های ری‌اکت (مثل `useState`) یا رویدادهای کلیکی کاربر نیاز قطعی باشد.
* کامپوننت‌های کلاینت باید تا حد امکان در پایین‌ترین سطح درخت کامپوننت‌ها قرار بگیرند.
* فایل‌های `page.tsx` در پوشه `src/app/` باید خلوت باشند و صرفاً کامپوننت‌های اصلی مربوط به ماژول خود را فراخوانی کنند.

---

## جریان انتقال داده‌ها (Data Flow)
* هوش مصنوعی موظف است جریان داده را به صورت خطی پیاده‌سازی کند و حق دور زدن لایه‌های معماری را ندارد.
* مسیر قطعی انتقال داده: `کامپوننت (UI)` ⬅️ `اکشن (actions.ts)` ⬅️ `سرویس (service.ts)` ⬅️ `مخزن (repository.ts)` ⬅️ `دیتابیس`.
* تمام داده‌های ورودی از سمت فرانت‌اند پیش از رسیدن به لایه سرویس، باید در فایل `validation.ts` همان ماژول به صورت کامل اعتبارسنجی شوند.
